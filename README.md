# i春秋 CTF 榜单采集器

一个基于**PySide6**的i春秋比赛观赛榜单采集工具。

使用方法很简单：
- 输入比赛链接并绑定比赛
- 按按钮导出需要的榜单到 Excel
- 或使用“一键采集”一次性导出全部榜单

---

## 功能特性

- 图形化界面（Windows 友好）
- 输入比赛 URL 后自动绑定比赛信息
- 显示比赛基础信息（标题、标识、访问令牌、观赛页、排行榜页）
- 支持打开观赛页 / 排行榜页链接
- 支持单独导出以下榜单：
  - 解题总榜
  - 积分总榜
  - 题目榜单
  - 单人总榜
  - 题型榜单（当前比赛所有题型）
- 支持“一键采集全部榜单”
- Excel 自动格式化：
  - 全单元格黑色边框
  - 水平/垂直居中
  - 列宽自适应（长文本列会加宽）
- 列头中文化策略：
  - 能在前端官方文案中确认的字段，使用官方中文列名
  - 无法确认的字段，保留原始英文键名，避免误翻译

---

## 支持环境

- Python 3.10+
- Windows（推荐）

> 理论上也可在其他桌面环境运行，但本项目主要针对 Windows 场景优化。

---

## 安装

```bash
pip install -r requirements.txt
```

---

## 运行

```bash
python app.py
```

---

## 使用方法

1. 在 GUI 中输入比赛地址（例如 `https://match.ichunqiu.com/2026hmg`）。
2. 点击 **绑定比赛信息**。
3. 绑定成功后，按需执行：
   - 点击某个单榜单按钮导出对应榜单
   - 或点击 **一键采集全部榜单** 顺序导出全部榜单
4. 在输出目录查看导出的 `.xlsx` 文件。

---

## 输出文件命名

统一格式：

`比赛标识_榜单名_YYYYMMDD_HHMMSS.xlsx`

示例：
- `2026hmg_解题总榜_20260328_103000.xlsx`
- `2026hmg_积分总榜_20260328_103002.xlsx`
- `2026hmg_题目榜单_20260328_103005.xlsx`
- `2026hmg_单人总榜_20260328_103010.xlsx`
- `2026hmg_题型榜单_20260328_103020.xlsx`

题型榜单为多 Sheet，每个题型一个 Sheet（具体题型随比赛而变化）。


---

## 简略技术说明

- 使用i春秋相关 API进行数据请求
- 通过签名参数和会话参数完成数据访问
- 绑定阶段会获取比赛详情和会话令牌
- 导出阶段按榜单接口分页抓取并写入Excel
