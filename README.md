# i春秋 CTF 榜单采集器

一个基于 **PySide6** 的 i春秋比赛观赛榜单采集工具，好用的话给个 star 吧🙏~ 🥺

![preview](https://github.com/user-attachments/assets/50dbd877-c199-4233-9c8d-4c5eb397360b)

使用方法很简单：
- 输入比赛链接并绑定比赛
- 按按钮导出需要的榜单到 Excel
- 或使用“一键采集”一次性导出全部榜单

---

## 功能特性

- 图形化界面（Windows 友好）
- 输入比赛 URL 后自动绑定比赛信息
- 显示比赛基础信息（标题、标识、访问令牌、观赛页、排行榜页）
- 支持打开观赛页 / 排行榜页链接
- 支持单独导出以下榜单：
  - 解题总榜
  - 积分总榜
  - 题目榜单
  - 单人总榜
  - 题型榜单（当前比赛所有题型）
  - **团队信息** ⭐ — 每个团队的每一位成员单独成行，含姓名、角色（队长/队员）、在线时长、签到状态、加入时间等
- 支持“一键采集全部榜单”，结束后弹窗汇总：**成功 N / 失败 M / 无数据 K**
- 单个榜单报错**不会中断**一键采集流程，会跳过并继续后续榜单
- Excel 自动格式化：
  - 全单元格黑色边框
  - 水平/垂直居中
  - 列宽自适应（长文本列会加宽）
- 列头中文化策略：
  - 能在前端官方文案中确认的字段，使用官方中文列名
  - 无法确认的字段，保留原始英文键名，避免误翻译

## 使用方法

1. 在 GUI 中输入比赛地址（例如 `https://match.ichunqiu.com/2026hmg`）。
2. 点击 **绑定比赛信息**。
3. 绑定成功后，按需执行：
   - 点击某个单榜单按钮导出对应榜单
   - 或点击 **一键采集全部榜单** 顺序导出全部榜单
4. 在输出目录查看导出的 `.xlsx` 文件。

---

## 输出文件命名

统一格式：

`比赛标识_榜单名_YYYYMMDD_HHMMSS.xlsx`

示例（以 `2026zggxdm3` 多模态伪造检测赛道为例）：
- `2026zggxdm3_解题总榜_20260822_184820.xlsx`
- `2026zggxdm3_积分总榜_20260822_184821.xlsx`
- `2026zggxdm3_团队信息_20260822_184822.xlsx`

> ⚠️ **该比赛没有数据时不会生成对应 Excel**：题目榜单 / 单人总榜 / 题型榜单返回 `暂无数据` 时，工具会跳过写入文件，并在汇总弹窗中以“⚠️ 无数据 N 个”的形式告知。仅成功导出的榜单才会出现在 `outputs/` 目录里。

题型榜单为多 Sheet，每个题型一个 Sheet（具体题型随比赛而变化）。团队信息为单 Sheet，每位成员一行，列含：队伍 ID / 队伍名称 / 排名 / 学校 / 成员名称 / 成员角色 / 总分 / 在线时长 / 加入时间等。

## 一键采集结束后的汇总弹窗

一键采集全部榜单完成后，会弹出类似这样的汇总：

```
共处理 6 个榜单：
  ✅ 成功 3 个
  ⚠️  无数据 3 个
  ❌ 失败 0 个

成功导出的文件：
  • 解题总榜 (22 行)   E:\outputs\..._解题总榜_...xlsx
  • 积分总榜 (22 行)   E:\outputs\..._积分总榜_...xlsx
  • 团队信息 (99 行)   E:\outputs\..._团队信息_...xlsx

无数据的榜单：
  • 题目榜单 — 题目榜单：暂无数据
  • 单人总榜 — 单人总榜：暂无数据
  • 题型榜单 — 题型榜单：暂无数据
```

失败明细会放在弹窗的“详细信息”折叠区里，方便展开查看完整 traceback 而不被截断。

## 简略技术说明

- 基础 API：`https://apiterminator.ichunqiu.com`
- 请求签名：`SHA1(sorted(payload) + "&" + SECRET)`，放在 `SIGN` 请求头
- 防脚本拦截：请求中携带 `User-Agent` / `Referer` / `Origin` 等浏览器头，规避阿里云 WAF 把 `python-requests/*` UA 一律 403 的问题
- 绑定阶段会获取比赛详情和会话令牌
- 榜单阶段按接口分页抓取：
  - `/match/rank/solved` 解题总榜
  - `/match/rank/team` 积分总榜
  - `/match/rank/question` 题目榜单
  - `/match/rank/person` 单人总榜
  - `/match/rank/category` 题型榜单
  - `/match/team/users` 团队成员（先拉所有 `team_id`，再逐队拉成员）
- **容错策略**：接口返回 `code=116 暂无数据` 时不当作错误，而是以“无数据”状态写出对应结果，便于汇总呈现；网络 / 接口异常会被收集为“失败”，不影响其他榜单。

## 常见问题

### Q: 点击“绑定比赛信息”后弹窗提示 403 / HTML 拦截页？

A: 通常是 WAF 拦截。本仓库已经附带浏览器 User-Agent 等请求头。如果遇到，可尝试：
1. 升级 `collector.py` 顶部 `IChunQiuCollector.USER_AGENT` 为更新版本的 Chrome UA。
2. 检查 `ICHUNQIU_BASE_API` 环境变量是否需要指向备用域名。

### Q: 一键采集结束，弹窗里“成功”很少，很多都是“无数据”？

A: 这通常不是工具问题——某些比赛（如多模态伪造检测赛道）天然就没有题目 / 单人 / 题型数据。绑定信息中的比赛标题会指明赛道类型；切到传统 CTF 题目赛（如 `2026hmg`）就会有完整数据。
