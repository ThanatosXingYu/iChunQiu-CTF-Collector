# i春秋 CTF 榜单采集器

基于 PySide6 的桌面端比赛数据采集工具。输入 i春秋比赛地址并完成绑定后，可以将公开观赛数据整理为格式化的 Excel 工作簿。

## 功能

- 根据比赛地址自动获取比赛标题、标识、时间和观赛链接
- 单独导出指定数据，或通过“一键采集”依次导出全部数据
- 网络请求和 Excel 写入在工作线程中执行，避免阻塞界面
- 单项导出失败时继续处理后续项目，并在完成后统一汇总
- 支持主动取消任务；关闭窗口时会等待当前任务完成清理后退出
- 对连接失败、限流和临时服务端错误执行有限次数重试和退避
- 分页数据缺失时整项标记为失败，避免生成不完整但显示成功的文件
- 对 `code=116` 等无数据响应进行区分处理，不创建空 Excel 文件
- 自动设置表头样式、单元格边框、对齐方式和列宽
- 使用 Qt 桌面服务打开输出目录，支持 Windows、macOS 和 Linux

## 支持的数据

| 数据类型 | 输出形式 | 说明 |
| --- | --- | --- |
| 解题总榜 | 单 Sheet | 队伍排名、总分、解题数和已解题目等 |
| 解题动态 | 单 Sheet | 解题时间、队伍、题目、分类和解题顺序等 |
| 积分总榜 | 单 Sheet | 队伍积分排名信息 |
| 题目榜单 | 单 Sheet | 题目维度的榜单数据 |
| 单人总榜 | 单 Sheet | 个人维度的榜单数据 |
| 题型榜单 | 多 Sheet | 每个题型写入独立 Sheet |
| 团队信息 | 单 Sheet | 每位成员一行，包含队伍、角色和在线状态等信息 |


## 运行环境

- Python 3.10 或更高版本
- Windows、macOS 或带桌面环境的 Linux

## 安装

建议在虚拟环境中安装依赖：

```bash
python -m venv .venv
```

Windows：

```powershell
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

macOS / Linux：

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 使用

启动应用：

```bash
python app.py
```

操作流程：

1. 输入比赛首页或观赛链接。
2. 点击“绑定比赛信息”，等待比赛信息加载完成。
3. 选择输出目录和分页大小。
4. 导出单项数据，或点击“一键采集全部榜单”。
5. 在结果弹窗或运行日志中查看导出状态。

任务运行期间可以点击“取消任务”。取消后，已经完整生成的文件会保留，当前正在写入的未完成文件会被清理。关闭窗口时如果仍有任务运行，应用会先请求取消，并在工作线程退出后自动关闭。

## 输出规则

文件名格式：

```text
比赛标识_数据类型_YYYYMMDD_HHMMSS.xlsx
```

例如：

```text
2026zggxdmf1_解题总榜_20260828_183339.xlsx
2026zggxdmf1_解题动态_20260828_190000.xlsx
2026zggxdmf1_团队信息_20260828_190001.xlsx
```

导出状态分为：

- `success`：数据获取和文件写入均成功
- `partial_success`：已生成可用文件，但部分团队成员数据获取失败；失败明细会显示在结果中
- `no_data`：接口明确返回无数据，不创建 Excel 文件
- `failed`：请求、解析或文件写入发生错误

一键采集会分别统计以上四种状态。某一项失败不会中断其他导出任务。

## 配置

以下环境变量可用于覆盖默认接口配置：

| 变量 | 说明 |
| --- | --- |
| `ICHUNQIU_BASE_API` | API 基础地址 |
| `ICHUNQIU_API_SECRET` | 请求签名参数 |

通常无需设置这些变量。接口协议发生变化时，可以通过环境变量进行本地调试，而不必直接修改代码。

## 注意事项

- 可导出的字段和数据范围取决于比赛类型及观赛接口实际返回内容。
- 比赛没有某类榜单时，该项会显示为“无数据”，不会生成占位文件。
- 解题动态通常可以完整获取；选手动态属于服务端维护的近期状态流，不在当前导出范围内。
- 请合理设置请求频率，并遵守目标平台的服务规则。
